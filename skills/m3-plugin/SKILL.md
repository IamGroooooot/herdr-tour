description: "herdr tour 중급 3/3: 팀에 반응하는 plugin을 만들어 로컬에 설치한다."
---

1. README.md의 예시 중 하나를 나한테 고르게 해 줘. 둘을 엮어도 좋아.
2. `~/herdr-plugins/<id>`에 `herdr-plugin.toml`과 `plugin.sh`를 새로 써 줘. 시작 코드에서 출발해.
3. `herdr plugin link`로 설치하고, trigger를 직접 일으킨 뒤 `herdr plugin log list`로 돈 걸 확인해 줘.
4. 내가 써 보고 고치자고 하면 바로 고쳐 줘.
