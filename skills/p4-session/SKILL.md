---
name: p4-session
description: "herdr tour 고급 4/4: sandbox session을 껐다 켜며 무엇이 돌아오는지 본다."
---

1. 새 pane에서 `herdr --session tour-s server`로 따로 server를 띄워 줘.
2. 거기에 workspace를 만들고, pane 하나는 그냥 `vim`, 하나는 resume 명령을 보고한 pane으로 만들어 줘.
3. `herdr session stop tour-s` 뒤 다시 띄우고, 무엇이 남고 무엇이 새로 시작됐는지 나란히 보여 줘.
4. 끝나면 sandbox session을 지워 줘.
