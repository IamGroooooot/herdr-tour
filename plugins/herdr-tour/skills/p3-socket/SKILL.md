1. 이 skill 폴더의 `live.py`를 새 pane에서 띄우고, 브라우저로 열 주소를 알려 줘.
2. 옆 pane에서 `herdr agent wait pm --until working`도 걸어 둬.
3. 내가 브라우저에서 pm에게 프롬프트를 보내면, 표는 계속 바뀌고 `agent wait`는 한 번 받고 끝나는 걸 같이 봐 줘.
4. 끝나면 두 pane을 닫아 줘.
